MELIS & KADIR WORLD - TEK OTORITER TOP FIZIGI DUZELTMESI

Kurulum:
1. Bu klasordeki kafa-topu.html dosyasini GitHub deposunun ana dizinine yukleyin.
2. Var olan kafa-topu.html dosyasinin uzerine yazin.
3. Commit changes yapin.
4. Her iki cihazda oyunu tamamen yenileyin (Ctrl+F5 / telefonda sayfayi yeniden yukleyin).

Bu surumde katilan oyuncuda ikinci bir top fizik simülasyonu kapatildi.
Topun gercek konumu ve carpismalari ev sahibinin otoriter fizik hesabindan gelir;
katilan oyuncu bu konumu hiz/ivme tahminiyle yumusak goruntuler. Katilan oyuncunun
kendi karakteri yerel tahminle hareket etmeye devam eder.
